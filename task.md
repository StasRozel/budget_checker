Нужно создать телеграмм бота который будет следить за бюджетом
Стек технологий: nodejs telegraf mongodb
Функционал бота: 
1)Добавить доход/расход 
Пользователь добавляет запись о расходе или доходе

2)Просмотреть бюджет
Пользователь может увидеть бюджет с всех балансов 

3)Создавать несколько балансов
Пользователь может создавать несколько балансов

4)Выводить статистику по доходу и затратам за период, статистика должно содержать в себе области куда были потрачены деньги или откуда получены
Будет предложена неделя месяц год, пользователь выбирает сам предложение должны быть в виде кнопок

5)Добавлять самому теги (области) для получения и затрат

6)Уведомление от бота с напоминанием о том чтобы внести записи о доходах и расходах


Все операции должны быть функции должны вызываться с помощью клавиатуры
то есть будут кнопки :
Создать запись (1)
Просмотреть бюджет (2)
Создать новый баланс (3)
Просмотреть статистику (4)
Добавить новый тег (5)

Создавай все не в одном файле, у нас будет структура вот примерный план:
index.js подчлючение бота и бд
/handlers  обработчик для каждой комадны
repository.ts обработка запросов к бд
по необходимости сервисы для 

строка подключения к бд и токен бота будет в env
